# Bundled Components

- ReShade 6.8.0: https://github.com/crosire/reshade
- DXVK: https://github.com/doitsujin/dxvk
- OtisFX CinematicDOF: https://github.com/FransBouma/OtisFX
- ReShade shader collection: https://github.com/crosire/reshade-shaders
- qUINT: https://github.com/martymcmodding/qUINT
- prod80 shader collection: https://github.com/prod80/prod80-ReShade-Repository
- Generic Depth add-on: bundled with the official full add-on ReShade build

The package contains local copies of the runtime and shader files used by the
tested configuration. Refer to each upstream project for its license and
source code.
