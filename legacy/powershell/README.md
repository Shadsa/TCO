# Retired PowerShell implementation

This directory preserves the pre-1.1 PowerShell installer and its package
manifest for historical comparison. The native Avalonia application does not
load, invoke, package, or update these files.

This snapshot is not a supported installation entry point. Its relative payload
paths reflect the former repository layout and are intentionally left frozen;
use the self-contained `TCO.Installer` application for current installs.
